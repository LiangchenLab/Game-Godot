# 岭行 · 三端导出说明（可复现草稿）

**引擎：** Godot 4.x（以本机安装的 4.x 为准，建议 ≥ 4.3）  
**工程根：** 本仓库根目录（含 `project.godot`）

## 通用

1. 打开工程 → 项目 → 导出  
2. 预设名建议：`Android` / `iOS` / `HarmonyOS`（可按宿主改名，本文用此三名）  
3. 包名占位：`com.liangchenlab.lingxing`（定稿前勿上架）  
4. **勿提交** keystore / 证书到 git

## Android

1. 安装 Android Build Template（编辑器提示时一键）  
2. 导出预设 → Export Path：`build/android/岭行-debug.apk`  
3. 调试：可用 debug keystore；发布：本机 keystore 路径用环境变量，不写死仓库  
4. 验证：安装 APK，触屏按钮可移动/跳跃，跑到旗

## iOS

1. 需 macOS + Xcode  
2. 导出 → 生成 Xcode 工程到 `build/ios/`  
3. Bundle Id 同包名占位；签名用个人/团队证书  
4. 真机或模拟器跑通一关

## HarmonyOS

1. 按团队当前 Godot→鸿蒙桥接方案（若尚未接好，本项记「路径待宿主确认」）  
2. 文档占位：导出产物目录 `build/harmony/`  
3. 验收同 Android：触控 + 通关

## 已知坑

- Windows 上 iOS 无法本地签；只保证工程可导出中间产物说明完整  
- 自定义资源路径勿用绝对盘符  
- 触屏控件在桌面用键盘测：左右/跳需在「项目 → 输入映射」已配置
