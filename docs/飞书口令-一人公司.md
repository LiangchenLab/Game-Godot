# 岭行 · 飞书口令（一人公司）

理念：**飞书一句话 → OpenClaw 调度 → 真工具干活 → 你只看成果。**

## 怎么说

在任意游戏群，或私聊机器人，用前缀（`：` / `:` 都行）：

| 口令 | 谁干 | 真工具 |
|------|------|--------|
| `Cursor：看下现在正常不` | 本机 Cursor | 监控领走执行 |
| `研发：把跳跃再调软一点` | Claude Code | `E:/cw/Game-Godot` 直接改代码 |
| `Claude：…` | 同上 | 同上 |
| `设计：调整第一关节奏说明` | game-design | 文档 / Figma MCP（已接则改稿） |
| `Figma：…` | 同上 | 同上 |
| `产品：本周只做通关稳定` | game-product | 里程碑等文档 |
| `美工：核对商店图标` | game-art | assets/store + 清单 |
| `测试：跑 MVP 用例留证据` | game-qa | evidence 目录 |
| `市场：定稿商店一句话` | game-market | 商店材料 |

无前缀时：在**哪个群**就按该群角色的默认工具链（研发群→Claude Code，设计群→设计…）。  
私聊无前缀：调度会按关键词粗分，分不清就先交产品拆任务。

## Cursor 标识

只要句子以 **`Cursor：`** 开头，就会进 Cursor 收件箱；本机 Cursor 监控（约 5 分钟一轮）领走并执行。  
这就是「飞书找到正在跑的 Cursor」的方式。
