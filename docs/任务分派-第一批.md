# 岭行 · 第一批任务分派

> 与 `里程碑-MVP.md` 配套。请各角色在对应飞书群认领并回进度。

## Game-设计

1. 基于现有一关，输出「关卡结构修订」到 `docs/关卡设计-MVP.md`  
   - 节奏：教学段 → 加压段 → 收尾  
   - 检查点位置建议、尖刺/史莱姆密度、星星分布  
2. 列出 5 条手感标准（跳跃高度、Coyote/缓冲是否需要、死亡惩罚等）  
3. 完成后 @ 研发，附文件路径  

## Game-美工

1. 审查 `assets/` 与 `store/icon-1024.png`，列出缺失/不统一项  
2. 需要时用 `python tools/make_art.py` 再生，保持像素风格  
3. 产出商店截图用「关键帧」清单到 `docs/美术清单-MVP.md`（可先文字）  

## Game-研发

1. 对照设计手感标准，改 `scripts/` / `scenes/`（小步可运行）  
2. 补 `docs/导出说明-三端.md`：Android / iOS / HarmonyOS 导出步骤与本机前置  
3. 能跑通的改动优先提交；卡点飞书同步  

## Game-测试

1. 等研发给出版本后，按验收标准写 `docs/测试用例-MVP.md` 并执行  
2. 阻断 bug 直接回研发群；日报写 `docs/测试报告-MVP.md`  

## Game-市场

1. 起草 `docs/商店材料-MVP.md`：应用名、一句话、长简介、关键词、截图文案  
2. 标注三端商店差异（权限、年龄分级、隐私链接占位）  

## Game-产品

1. 维护本里程碑与分派文件，收口每日进度  
2. 变更范围必须先改 `里程碑-MVP.md` 再分派
