# 岭行 · 关卡设计 MVP

> 实现：`scripts/level.gd` → `_build()`（代码拼装，非 TileMap）  
> 手感：Coyote 0.1s + Jump Buffer 0.1s（`scripts/player.gd`）

## 三段节奏

| 段 | 约 x 范围 | 目标 | 允许威胁 |
|----|-----------|------|----------|
| Act1 教学 | 0 → ~1400 | 跑、跳缺口、收星 | 无尖刺/史莱姆；首缺口后可出现**单**尖刺 |
| Act2 加压 | ~1500 → ~3500 | 高度、移动台、巡逻怪 | 尖刺、史莱姆、掉坑；中段检查点 |
| Act3 收尾 | ~3600 → 旗 | 阶梯上升、收尾星、过旗 | 轻量；旗前留落地平台 |

## 布局要点（与代码同步）

1. **教学平地**：足够长，地上 3+ 星引导向右。
2. **首缺口**：宽度约 3–4 格，落地后再放尖刺，避免「第一跳即死」。
3. **检查点**：加压段中后部高台，复活后仍面对后半压力。
4. **史莱姆**：检查点后平地巡逻，左右限写死避免冲出平台。
5. **收尾阶梯**：3 级上升平台 + 底部大平台放旗；旗附近 2 星。

## 不做

多关切换、时间攻、隐藏路线、Boss。
