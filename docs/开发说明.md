# 开发说明

## 这一版

- 像素角色，有站立、跑步、跳跃。
- 关卡包含地面、高台、移动平台、尖刺、史莱姆、检查点和终点。
- 12 颗星星。
- 开始、暂停、过关界面。
- 键盘和屏幕按钮都能操作。

## 入口

`scenes/main.tscn` 负责天空、地面色和界面。`scripts/level.gd` 在 `_build()` 里摆关卡，改坐标就改关卡。

角色在 `scenes/player.tscn`。脚底是节点原点，生成时的 y 要落在平台顶面附近。

## 碰撞

| 层 | 用途 |
| --- | --- |
| 1 world | 平台 |
| 2 player | 角色 |
| 3 pickup | 星星、旗帜、尖刺、史莱姆、掉落区 |

## 画面

`tools/make_art.py` 用 Pillow 画像素图，输出到 `assets/`。角色表从左到右是：站立、四帧跑步、跳跃。

贴图过滤在脚本里设成最近邻，避免像素被糊掉。
