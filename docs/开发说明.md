# 开发说明

## 这一版有什么

- 角色左右移动和跳跃，镜头跟着走。
- 一段从左到右的关卡：地面、高台、一块左右移动的平台。
- 8 颗星星。吃到会计入左上角。
- 掉出画面下方会回到出生点。
- 碰到红旗显示过关。

画面用纯色块搭的，没有外部贴图，方便先看手感。

## 场景怎么串起来

`scenes/main.tscn` 是入口。里面有天空、远山、`Level` 和 `HUD`。

`scripts/level.gd` 在运行时生成平台、星星、红旗和角色。改关卡直接改 `_build()` 里的坐标。

`scenes/player.tscn` 是角色。碰撞盒脚底对齐节点原点，所以生成位置的 y 要放在平台顶上。

## 碰撞层

| 层 | 用途 |
| --- | --- |
| 1 world | 平台 |
| 2 player | 角色 |
| 3 pickup | 星星、红旗、掉落区 |

角色只和世界层碰撞。星星和红旗只检测角色。

## 之后接到手机

这一版先在电脑里用键盘看。导出到 Android / iOS 时再加虚拟按键，并在 Godot 的导出面板里填各端的 SDK 路径。商店账号、图标和隐私政策留到能稳定玩通之后再做。
