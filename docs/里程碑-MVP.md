## 一句话目标

打磨现有可玩一关，补齐上架所需素材与导出链路，形成可提交商店的最小版本。

## 当前基线（已有）

- 2D 横版一关可运行（Godot 4.x）
- 玩家移动/跳跃、检查点、尖刺、史莱姆、星星、红旗过关、手机虚拟按钮、HUD

## MVP 范围

### 必须有

1. **玩法稳定**：一关完整闭环；死亡回检查点；星星不丢；暂停可用  
2. **手感可接受**：跳跃/移动不“飘”、碰撞无明显穿模  
3. **内容完整感**：起终点明确、至少 1 个检查点、若干障碍与收集物  
4. **美术一致**：像素风格统一；商店 1024 图标可用  
5. **三端可导出**：Android / iOS / HarmonyOS 导出说明与可复现步骤（鸿蒙按本机可用插件/版本落地）  
6. **商店材料**：应用名、简介、截图清单、隐私/权限说明草稿  

### 明确不做（MVP 外）

- 多关卡章节、联网、内购、账号系统、复杂剧情
