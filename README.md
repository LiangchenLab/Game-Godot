# 岭行

一个用 Godot 4 做的 2D 横版跳跃示例。角色从左侧出发，跳过缺口和平台，收集星星，走到红旗过关。

## 怎么跑

1. 安装 [Godot 4.3](https://godotengine.org/download) 或更新的 4.x。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 按 F5，或点编辑器右上角运行。

## 操作

| 按键 | 作用 |
| --- | --- |
| A / ← | 向左 |
| D / → | 向右 |
| 空格 / W / ↑ | 跳跃 |

掉进坑里会回到起点。走到最右侧红旗后角色停止，画面中央显示收集数量。

## 目录

```
scenes/          主场景、角色场景
scripts/         角色、关卡、星星、终点、界面
docs/            开发和后续上架说明
project.godot    Godot 工程入口
```

更细的说明见 [docs/开发说明.md](docs/开发说明.md)。
