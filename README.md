# 岭行

一款 2D 横版跳跃游戏。沿山路向右跑，跳过缺口和尖刺，躲开史莱姆，收集星星，走到红旗过关。

## 运行

1. 安装 [Godot 4.3 或更新的 4.x](https://godotengine.org/download)。本机建议用 4.7。
2. 打开 Godot，导入本目录的 `project.godot`。
3. 第一次要先点「编辑」，等资源导入完成。
4. 在编辑器里按 F5 运行。项目列表里的「运行」要等导入之后才能用。

如果弹出「将修改为 Godot 4.7」，直接确定即可。

## 操作

| 操作 | 键盘 | 屏幕 |
| --- | --- | --- |
| 向左 / 向右 | A D 或方向键 | 左下角「左」「右」 |
| 跳跃 | 空格、W 或上 | 右下角「跳」 |
| 暂停 | Esc | 右上角「暂停」 |

点「开始」后角色才会动。掉进坑、碰到尖刺或史莱姆，会回到最近的蓝色旗帜；还没碰到旗帜时回到起点。已经捡到的星星不会消失。

## 目录

```
assets/     像素图
scenes/     主场景和角色
scripts/    玩法脚本
store/      商店用的 1024 图标
docs/       玩法、开发和上架说明
```

重新生成像素图：

```bash
python3 tools/make_art.py
```
